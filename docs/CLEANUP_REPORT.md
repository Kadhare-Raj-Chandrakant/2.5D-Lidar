## 4. Reason for Removal

All removals strictly adhere to the project's sanitization guidelines:

1. **AI Conversation Artifacts (Category 1)**:  
   `brag-output/` was produced during automated assistant launch video generation. It contains promotional text, model-generated briefs, and planning markdown that do not serve any algorithmic, architectural, or runtime function.
2. **Visual Artifacts & Redundant Exports (Category 2)**:  
   The image files in `assets/ppt_images/` and the screen recordings in `scripts/` are redundant UI captures, duplicate visual dumps, and test frames created for external presentations or diagnostics. They are not referenced by `README.md`, `ARCHITECTURE.md`, or any code import.
3. **Execution & Cache Artifacts (Category 3)**:  
   `fovea_lidar/live_server.log` is a dead runtime log containing timestamped HTTP requests and an aborted connection traceback. `__pycache__` and `.pyc` files are transient bytecode caches regenerated automatically during Python execution. `web-ui/dist/` is an ephemeral client build output governed by `.gitignore`.
